Question #7: Explain why sort() alone could NOT have been used to reorder the whole students data frame by score (try to imagine running sort(students) and think about what “sorting a table” would even mean). Why is order() the correct tool whenever you need to keep multiple related columns lined up with each other? ```{r} # Reorder the entire students data frame students[order(students$score), ] ``` Answer:The sort() function is designed to arrange individual values in a vector, not to rearrange an entire data frame while keeping all columns connected.
